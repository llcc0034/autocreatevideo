# 场景专项规则

- 场景 ID：`media-asset-production`。
- 场景名称：媒体资产与内容生产平台。

## 场景：媒体资产与内容生产平台

- **定位与阶段**：当前为个人/早期开发的AI媒体资产与短剧生产平台；先实现可用的业务闭环，不套用多人版权审批、签入签出、生产级SLA或归档认证作为默认前置需求。
- **两类业务入口**：短剧生产由剧本生成/结构化提取实体、主图/变体设定和镜头素材需求，再由配方自动生成、入库并传给下游；素材库也可独立上传、选取或调用模型生成。两者复用同一素材与执行能力，不要求全自动短剧提前在素材库备好素材。
- **平台基础能力**：字段定义、输入/输出结构、解析、来源及装配映射共用配置；新增受支持类型的业务字段不逐字段编码。配置决定业务格式和处理策略，代码实现通用解析、真实引用及执行协议。
- **模块职责**：Bible维护实体与变体设定；素材库独立管理文件、主图/变体关联和版本；生成能力供素材库及配方共同调用；镜头/提示词使用确切素材引用，不复制第二套素材或凭译名猜图片。
- **主图与变体**：模型生成变体时，必须实际输入选定主图及变体差异设定，不能分别文生图冒充参考生成；上传/复用已有变体只建立真实关联，不强制重生成。自动或人工选择按流程配置，不能把全自动生产硬改为逐步人工审批。
- **提示词分工**：图片生成使用外观锚点与变体设定；参考生视频使用素材引用名称及动作、镜头、时间、对白/声音，不反复注入已有参考图的外观锚点。名称语言不限，素材身份与本次输入位置必须对应。
- **开发数据**：不适配新逻辑的历史测试数据及关联审计可按明确范围清理，不为旧记录兼容；模拟测试费用不是清理条件。不伪造保留结果，不误删共享有效素材。
- **模块验收**：每个业务模块交付可操作入口和独立样例，验证成功、缺输入、失败与恢复；最后再验新剧本/新配方整链。代码/隔离测试、服务加载和真实媒体效果分别记录，延期的数据库、容量及分发工作不自动加入。
