# AutoPrompt 原创参考素材库

这是项目随附的本地短剧参考素材库。全部画面均在本项目开发过程中通过 OpenAI 内置图片生成能力从零生成，没有下载或混入第三方图库、影视剧截图、明星肖像、品牌素材或既有 IP。

## 内容

- 11 种风格：武侠、玄幻仙侠、国创动漫、心理惊悚、民国侦探、都市剧情、未来科幻、古装权谋、末日废土、治愈奇幻、魅影风华。
- 每种风格包含 3 个人物、3 个无人场景、3 个独立道具，共 99 张可直接引用的 JPG 卡片。
- 每个风格目录保留一张带原始生成元数据的 `master.png` 九宫格母版。
- [`manifest.json`](./manifest.json) 记录每张卡片的名称、用途、提示词锚点、路径、SHA-256、母版关联及来源说明。
- [`generation-prompts.md`](./generation-prompts.md) 记录生成与修订提示词。

所有卡片都由 [`scripts/build_asset_library.py`](../../scripts/build_asset_library.py) 从母版的真实分隔线裁切。脚本会校验母版结构，避免把相邻格内容裁入当前素材。

## 使用约定

人物素材是长期不变的 canonical identity reference；上一镜头末帧只能作为动作、构图或连续性参考，不能替代人物 canonical 素材。场景与道具也应绑定 manifest 中的稳定资产 ID，并在剧集 Bible 里版本化。

视觉锚点建议只写跨镜头不变化的事实：人物写固定身份、五官发型、服装层次、材质、主色和随身标记；场景写空间布局、建筑结构、主要物件、材质、主色、光源方向和天气氛围；道具写外形轮廓、尺寸比例、材质、纹样、磨损和可识别标记。语言不作为素材库完整性硬校验；但同一条锚点建议整段全中文或整段全英文，避免中英混杂。

素材库保留来源母版、裁剪范围与文件哈希，便于验证卡片生成和裁剪链路。
