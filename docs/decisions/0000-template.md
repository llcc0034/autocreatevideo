# NNNN — 决策标题

- 状态：有效
- 适用范围：填写组件、数据或运行边界
- 责任文档：填写 `docs/architecture.md`、`docs/operations.md` 或 `docs/mvp-requirements.md` 中的对应章节

## 当前上下文

说明当前业务目标、技术约束、安全边界、运行条件和需要作出选择的问题。只写理解该决策所需的事实。

## 决策

用明确、可执行的陈述写出采用的方案，并说明适用条件。

## 约束与不变量

- 列出实现必须保持的性质。
- 列出不得绕过的权限、数据、网络或运行边界。
- 列出并发、幂等、完整性或恢复要求。

## 不采用的选择

- 选择：说明它不满足当前约束的直接原因。

## 影响

说明该决策对代码、配置、数据、测试、运行资源和操作流程的直接影响。风险与限制使用当前态表述。

## 验证

- 自动检查：列出测试、静态检查或契约验证命令。
- 运行检查：列出目标环境必须满足的可观测条件。
- 验收证据：列出需要保存的脱敏结果、哈希、状态或指标。

未实际执行的检查标记为“待验证”，不得写成已通过。

## 复核条件

列出会使当前约束不再成立的明确条件，例如安全边界、数据模型、部署拓扑、依赖契约或资源上限不再满足。
