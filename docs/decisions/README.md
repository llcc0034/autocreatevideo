# 当前架构决策

本目录只管理对当前实现具有约束力的架构决策。每个决策说明当前约束、明确选择、适用边界、可验证不变量和复核条件，不承担发布记录、工作日志或实现过程说明。

## 收录条件

决策文件必须同时满足：

- 影响两个及以上组件，或形成长期安全、数据、运行边界；
- 存在需要明确排除的可行选择；
- 能通过代码、配置、测试或运行检查验证；
- 状态为“有效”，并且实现与文档一致。

局部实现细节放在代码与 [架构文档](../architecture.md)；命令和环境配置放在 [运维文档](../operations.md)；业务范围和验收条件放在 [MVP 需求](../mvp-requirements.md)。

## 文件规则

- 文件名使用 `NNNN-short-title.md`，编号只用于稳定引用。
- 正文使用 [0000-template.md](./0000-template.md) 的字段。
- 一个文件只表达一个决策。
- “决策”使用可执行陈述，“约束与不变量”给出禁止突破的边界。
- “验证”列出仓库内可执行证据和目标环境验收项，不写未经执行的成功结论。
- 有效决策必须与实现一致；发现不一致时，先完成代码、测试、职责文档和本索引的一致性处理。

## 有效决策索引

`0000-template.md` 是写作模板，不是架构决策。
