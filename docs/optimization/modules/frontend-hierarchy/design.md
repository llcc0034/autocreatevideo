#### 18.14.1 复核发现与统一交互目标

当前差距有具体落点：配方、执行实例、策略和模型作者已分段接入公共骨架、精确引用及保存恢复，详见18.14.6–14，完整适用分支仍未验齐。工作流列表详情、版本页和导入摘要已于18.14.15优先展示对外合同，但Projector作者及工作流完整导入／后继矩阵尚未收口。独立关系目录不等于所有资源的完整语义详情，字段／结构／来源／输出作者与素材详情未全部接入共同引用交互。其他页面仍有局部字号和层级差异；继续清理被替代规则，不以新增一层CSS覆盖或只读摘要代替作者流程。

统一的是用户理解顺序和维护归属，不是让每类资源都显示同一条执行链：

1. **用途**：这个对象解决什么问题、当前精确版本／状态是什么。
2. **输入与依赖**：从哪里获取内容，引用哪些公共资源；定义与本次具体值分开。
3. **处理或约束**：哪些由当前对象配置，哪些来自下层只读合同。
4. **输出或使用效果**：产物是什么、到哪里使用；定义类展示约束及使用方，不编造模型输出。
5. **实现详情**：技术标识、映射、原始合同和运行实现按需下钻。

| 模式 | 主展示及操作 | 不允许的混淆 |
| --- | --- | --- |
| 查看版本 | 紧凑用途摘要、输入／处理／输出或定义／约束／使用方；精确引用可下钻 | 不把不可操作的灰色完整表单当作默认详情，不按当前新配置补写旧合同 |
| 新建 | 按当前对象职责分段填写；同屏摘要解释刚选资源带来的输入与输出；可直接跳到需补内容 | 不要求先理解全部底层名词，不默认选择第一项，不自动保存或调用模型 |
| 编辑草稿 | 与新建同一作者骨架，显示已保存和未保存修改；服务端错误定位到所属分段 | 不丢弃失败请求中的已填值，不把本地预览当成后端已认可 |
| 创建后继 | 明确基于哪个精确版本；沿原作者能力创建独立草稿并显示变更范围 | 不修改原发布版本，不自动替换配方等使用方的引用 |

大表单采用页内分段导航加当前内容，必要时使用独立作者页；小对象继续复用现有弹框。不是强制每段保存、逐项确认的向导。桌面以内容区为主，摘要与导航从简；窄屏改为单列。下钻只读资源使用一个可返回的详情区域与面包屑，不层层叠弹框；复杂维护进入唯一作者入口，返回恢复原选择及尚未提交的表单上下文。离开或刷新可能丢失未保存内容时明确提醒，不把会话草稿当服务端配置。

#### 18.14.2 各对象的查看与新增路径

以下是目标交互，复用已有页面、目录、writer和权限，不代表这些页面已全部改造。

| 对象 | 查看时的第一层 | 新建／草稿／后继时的理解顺序 | 维护边界 |
| --- | --- | --- | --- |
| 配方 | 步骤列表／流程、每步职责、输入来源、输出去向 | 选择制作方式或已有服务端预设 → 编排步骤 → 生成步骤选择精确执行实例 → 配置来源、允许参数及选择／审核规则 → 复核整条数据流 | 不重复编辑实例内模型部署、工作流和提示词；审核／确定性处理显示真实职责 |
| 执行实例 | 能力与用途、输入准备、模型调用、输出约定 | 确定能力与兼容实现 → 按原流程保存必要组合并读取合同 → 配置输入来源／映射、文本处理和允许参数 → 核对输出 → 保存与发布操作 | 模型及工作流的约束只读引用；辅助实例属于按需文本输入处理；配置完成不等于Smoke通过 |
| 提示词策略 | 哪些字段进入、怎样处理、输出到哪个通道 | 选择用途与来源 → 选择字段／结构版本 → 配置保留、生成、翻译或组装规则 → 配置通道 → 使用现有预览能力复核 | 策略声明辅助需求，实际辅助实例在使用方绑定；无需要时不显示AI调用链，不重复模型连接配置 |
| 模型／能力版本 | 能做什么、接受什么输入、输出什么、有哪些部署 | 基本身份 → 能力与接口输入输出 → 约束 → 按现有生命周期保存／发布 | 仅显示模型可配置合同，不在上层复制工作流节点、VAE或LoRA管理 |
| 模型部署及连接／主机资源 | 部署哪个模型能力、使用哪个Provider、运行位置及实际状态 | 选择模型精确版本 → 选择已有连接／主机等资源 → 配置该部署允许的运行项 → 保存；校验另有明确动作 | 展示模型继承项与部署自有项；复用既有凭据管理，不向普通详情暴露敏感内容 |
| 工作流／Projector | 对外素材输入、可调参数、结果、识别状态 | 导入工作流／新增版本 → 查看原有识别结果与不支持项 → 调整允许的对外参数和动态输入输出规则 → 核对／保存；校验及Smoke另行明确操作 | 节点、内部接线和资源在实现详情；已支持自动识别沿原能力，不新增任意工作流自动理解，不要求普通用户重复接线 |
| 字段／结构 | 字段语义、类型／单位／约束、组织方式、精确版本、使用方 | 定义语义／类型 → 配置约束；结构从公共字段版本选择并组织层级 → 复核及保存 | 不为不同调用者复制同义字典；字段业务值不在此填写 |
| 内容来源／业务输出定义 | 从何种事实读取或如何解析结果、适用结构及使用方 | 选择已有类型与结构 → 配置本对象允许的读取／解析规则 → 复核及保存 | 只配置现有算法／合同允许项，不在前端新增解析器或伪造可用来源 |
| 素材 | 内容预览、媒体信息、来源说明、已有可查使用关系 | 上传／生成入口保持独立 → 填写素材自有信息；生成任务引用执行实例 → 查看真实结果 | 素材不是配置版本，不强加后继／发布流程；来源说明独立保留，不因配置删除而要求重建历史 |

公共引用统一显示“名称＋精确版本＋状态”，并提供查看定义、查看使用方、前往维护。标识和SHA进入可复制详情，不作为默认大标题。未有版本概念的资源显示其真实身份，不编造版本。使用关系的种类与范围以原接口为准，不能把模型候选、校验关系或来源说明当作当前选定的执行依赖。需要新资源时前往唯一维护入口；返回后由用户显式选择新版本，不自动升级原引用。

#### 18.14.3 配置如何流转：H3参考生视频示例

这是作者交互示例，不是创建新配置、填入固定参数或发起真实生成的操作计划；H3只是验收样例，通用组件不得以模型名称判断路径。

1. **准备可复用资源**：已有兼容模型部署／工作流可直接选择；缺失时引导到其维护入口。模型及工作流对外合同共同决定有哪些参考槽位、参数与输出，界面只展示后台已有结果。
2. **新建执行实例**：选择参考生视频能力及其兼容实现。沿实际API的保存顺序先完成必要组合，不把尚未保存的组合冒充可读合同。保存按钮明确写“保存组合并配置输入”等真实动作，而不是没有反馈的“下一步”。
3. **输入准备**：参考媒体来自调用方按声明提供；显示媒体类型、角色／用途、数量与槽位约束。创作字段例如动作、运镜、对白只是用户定义字段的示例，字段身份和结构读取公共目录，不在组件写死。选择策略时展开来源→字段→处理→通道，按需显示其辅助需求和精确辅助实例；选择人工完整提示词则只填写适用通道，不同时强迫填写另一份策略输入。
4. **参数和输出**：帧数、尺寸、种子等只在确切合同声明时展示，区分接口要求、工作流固定值、实例覆盖和调用方输入；默认值／约束来源从已有服务端结果读取。输出读取已声明视频类型、输出节点与解析约定，不在配方另填一套。
5. **创建配方并引用**：参考生视频步骤选择刚保存／发布的精确实例，配置“当前镜头字段→实例字段”和“选定素材→实例参考输入”，下游按已有能力选择生成候选并用于装配。配方只维护本步骤绑定、来源及允许的覆盖，不再选择一次底层模型／策略／节点。
6. **复核**：展示“镜头字段／素材 → 输入准备（含按需辅助与策略） → H3能力的工作流实现 → 视频输出 → 下游使用”。这是配置路径；未提供本次素材或尚未生成的辅助值显示待提供／待生成，不生成虚构预览。Bible原名、描述和引用身份按已有保真合同原样传递，不受创作语言设置改写。

保存草稿、发布配置、校验、Smoke与启动生产是不同动作；进度只显示实际已完成配置分段和后端请求阶段，不用虚构百分比，不为本次纯前端优化自动触发调用。

#### 18.14.4 统一视觉与反馈规范

#### 18.14.5 实施顺序、复用落点与验收

1. **先公共基础（UI-H06、UI-H04）**：复用`BaseModal`、状态／错误组件、唯一设置导航、原关系目录与类型化选择控件，建立共享作者骨架和资源详情／返回交互。语义展示复用原DTO及读取服务，不新增第二套合同、业务默认值或前端执行器。公共样式主线单写。
2. **优先三类核心作者（UI-H07、UI-H08、UI-H09）**：先以执行实例统一查看和作者流程，再接配方及策略；每类同时验查看、新建、草稿修改与后继。不只做一个漂亮详情页而遗留原始新增表单。
3. **向下覆盖定义与实现（UI-H10、UI-H11、UI-H12）**：模型／部署、工作流／Projector和字段／结构／来源／输出／素材按各自职责接入，不强套可执行对象模板。独立文件可并行，涉及公共骨架／样式／导航的写入必须串行集成；不把未运行的代理称为运行中。
4. **全路径收口（UI-H05）**：类型检查、定向前端测试、构建、旧入口／重复样式搜索和真实浏览器逐项验收，更新指南与当前事实文档。每项提供具体页面／动作证据，不把现有96项外推成完整覆盖。

最终验收矩阵包括：

- 每类适用对象的查看、新建、草稿编辑、后继创建；非版本资源验证实际上传／编辑／维护流程，不编造模式。
- 三类核心作者从空表单到有效草稿的原API写入链在隔离环境验证；确切版本选择、必需字段、目录失败、并发变更／过期响应、更换组合影响、保存失败内容保留、重复提交与未知结果回读均有测试。
- 公共引用“查看定义→查看使用方→前往维护→返回”的精确身份及未保存表单状态；已有对象刷新保持定位，未保存刷新明确提示风险。当前配置解释与任务冻结事实分开。
- H3人工完整提示词与策略／辅助分支，以及不需要工作流或提示词的适用分支；图和表都来自相同合同，不编造连线、默认值或已发生的AI调用。
- 正式页面只读检查及隔离作者页面桌面／390px、键盘和错误恢复；记录实测尺寸，不用设置调用成功代替实际视口证据。
- 除2026-10-10已授权的H11原请求回执及只读恢复接口外，不变更后台合同／Schema；无重复公共定义或维护入口、无隐式现用配置覆盖。其他必需读取能力缺失仍须明确记录，不在前端猜造事实或擅自扩围。
