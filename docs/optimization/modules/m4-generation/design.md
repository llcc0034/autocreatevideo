## 8. M4 主图与变体素材生成

<a id="81-背景需求与产出"></a>

### 8.1 背景、需求与产出

参考一致性要求模型实际收到指定主图。自动配方从当次剧本发现需求，独立素材库从用户输入生成，二者共用实例、准备、队列、产物和素材登记。库内选择/上传可直接满足目标，不强制重新调用。

输入：生成目标、身份/外观或变体差异、确切实例版本、来源选择、候选/选择策略；变体另需确切主图素材版本。输出：调用记录、图片Asset/候选版本、实际依据与结果选择。失败/不支持时输出具体原因，不回退独立文生图。

<a id="82-实现方式与状态"></a>

### 8.2 实现方式与状态

- 复用`asset_generation.py`、`production_recipe_preparations.py`、`production_recipe_media_stages.py`和`execution_input_resolution.py`，提取共用素材目标准备/完成登记逻辑；调用者身份保留为原配方单元或独立AssetGenerationJob。
- 目标状态按已有准备/任务状态投影为：待来源→待主图→准备/排队/执行→有候选待选或自动选定→可下游使用；不建立一套平行状态数据库。
- 主图候选按配置选定后，逐个变体把该Asset作为图片输入映射到目标端口，同时提供变体差异。兄弟变体不默认参考彼此。
- 预检读取实例输入合同和Projector/端口配置：必须支持图片及用途；缺能力直接说明。配置错误修正沿原工作流/实例编辑器，不开发新的工作流平台。
- 已有素材满足目标与“已有图作为生成参考”明确区分；重复调度复用同一单元/请求，不多发调用。主图失败时下游等待/受阻，不发空图变体。
