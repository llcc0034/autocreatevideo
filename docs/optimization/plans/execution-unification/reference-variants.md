## 0.5 素材引用与 Bible 变体（OPT-REFERENCE-VARIANT-001，模块化目标与已有证据）

<!-- source-section 45bbda69c2e4 -->
<a id="051-范围与需求优先级"></a>

### 0.5.1 范围与需求优先级

本节保留目标方案概述与已有实现边界，不是已交付说明。模块顺序见[总览](../../backlog-review-2026-09-28.md#module-plan)，最新细任务/依赖/验收以[独立详细设计](../../module-development-detailed-design-2026-09-28.md)审核结果为准，不能按下方旧工作包自行扩项；实现证据在0.5.7。复用现有字段/实例/配方/准备/队列及Asset，不建立第二套执行或素材事实。

1. **剧本源头产生需求**：生成/结构化合同声明本次实体、共同身份、主图锚点、变体差异、场景/可见对象/发言人及逐镜素材用途。内容在运行中产生，不要求事先在素材库创建人物或图片，也不由最终正文按译名反推关系。
2. **两个业务入口**：配方根据剧本自动生成所需主图/变体并入库传递；素材库可以无剧本、无配方独立上传、选已有素材或调用同一生成能力。素材库是独立管理模块，不是自动短剧的手工前置阶段。
3. **主图真实依赖**：模型生成变体时输入明确选定的主图文件及变体差异设定，不能分别文生图或以主图文字代替图片；自动规则或人工操作均可完成选定。上传/复用已有变体只建立真实关系，不强制重新生成，不伪造参考生成来源。兄弟变体默认参考同一明确主图，不隐式串联。
4. **平台配置化**：字段、结构/解析、来源、映射、生成要求及自动/人工策略可配置，代码不写死人名、服装、语言、模型或某配方。新增受支持类型的字段不用再编码；全新执行器、未知解析算法或业务动作不凭字段配置自动获得。
5. **素材命名与身份**：名称可用任何语言，是可读引用名而不是Asset身份或固定图片编号。主图、变体和候选版本分开；本次素材ID、用途和输入顺序决定实际槽位，集中展示一次名称对应关系。
6. **视频动态提示词**：辅助任务和最终装配不重复注入Bible外观锚点、参考图生成提示词、prompt_hint或保留分析；正文聚焦动作、交互、构图/运镜、时间、原对白与声音。图片生成仍使用身份锚点和变体差异，两者不混淆。
7. **操作可用与结果真实**：审核/选择由流程配置，不强制全自动链逐步人审；自动选择如实记为自动来源，不冒充人工。保留全文、实际参考顺序、错误及质量建议；必要输入/引用/接口错误明确处理，主观质量不硬阻断。

<a id="052-两种入口与事实划分"></a>

### 0.5.2 两种入口与事实划分

```text
自动短剧：
字段/剧本规则配置 → 剧本生成/结构化 → 本次实体/变体/镜头素材需求
  → 配方调用M4：生成主图 → 参考主图生成变体
  → 同一素材库保存及关联 → 按声明自动装配镜头输入 → 提示词/视频/交付

素材库独立操作：
上传/选择/生成主图 → 上传/选择/参考主图生成变体 → 同一素材库

字段装配：
本次上游结果 / 指定Bible主图或变体 / 已有素材 / 本地上传后入库素材
```

这是职责与依赖示意，不把上述文字当成已存在的stage/API名称。正式接线随模块实现同步到Schema、OpenAPI、页面和测试。全自动链不要求每镜重选素材；已有素材明确满足目标时可配置跳过该目标生成，其余需求继续生成，不能偷偷用无关图补缺。

| 事实层 | 职责 | 约束 |
| --- | --- | --- |
| 字段及结构合同 | 共用字段定义、格式、类型/空值及映射 | 不存某次实际素材，不复制第二份配置 |
| Bible及主图/变体设定 | 稳定实体、身份锚点、造型差异及剧本/人工来源 | 不是素材库副本；名称不充当图片ID |
| 素材库 | 图片/视频/音频等文件及版本、主图—变体关联、可选Bible归属 | 素材可以独立于Bible；同一文件/身份不因两个入口重复保存 |
| 生成准备 | 本次设定、主图文件、实例、参数及输出目标 | 生成变体必须有真实主图输入；上传的图不伪记为生成结果 |
| 选择与审核 | 配置的自动选择或明确人工决定 | 自动不冒充人审；不强制增加人审，不能无规则取最新 |
| 镜头素材使用 | 确切素材/版本、用途、引用名、输入次序 | 不凭译名或列表位置猜人物，不把所有素材都塞入每镜 |

同一变体可有多个生成版本或视角；不同服装是不同变体，不等于重试编号。主图更换不自动改写已生成/已提交变体的来源；未执行项按新选择明确更新，是否重新生成由操作或配方配置决定。清理不适配的开发记录按0.5.9，不通过兼容层解释旧数据。

#### 平台字段基础（M1；全链消费者随所属模块接入）

1. **定义与使用分开**：定义稳定标识、显示名/含义、类型、单位/枚举等；输入/输出结构组合字段为对象、列表和媒体引用。步骤必填/可选、空值、数量和显式默认值属于使用关系，不能一个步骤必填就全平台必填。区分不存在、null、空、false和0。
2. **生成、解析、表单、消费同源**：JSON字段名/层级/集合按配置映射；生成要求、返回解析、审核展示及下游目录读同一合同。支持的分隔格式也可配置；未知自由文本通过结构化步骤转换，不能承诺无配置准确理解任意文本。
3. **业务语义明确映射**：字段说明帮助人和模型理解，业务动作仍绑定实体、设定、关系、时间等语义输入；自定义创作字段可直接进入提示词，不因没有数据库专列而丢失。不按字段名字猜人物或变体。
4. **媒体来源可选**：本次上游结果、Bible主图/变体、已有素材和上传后Asset均为正式来源；页面展示允许来源及具体对象。本次改选不暗改Bible默认图。生成目标已由选定素材满足时，不重复调用模型；混合来源的剩余目标继续按规则生成。
5. **有限通用引擎**：代码实现类型、结构遍历/映射、实际引用、执行协议；业务字段组合走配置。新增受支持类型字段不用写解析分支；全新协议/算法仍需开发，不开任意脚本或数据库路径。
6. **最小版本与预览**：保存/使用时给出样例解析、错误路径和下游预览，执行记录实际合同/映射版本；不额外建设多层发布审批。旧固定业务字典和解析生产路径删除，不兼容无价值历史数据。保留的请求仍是真实原请求，不用新配置伪造。
7. **渐进交付**：M1先用两种布局、一个非剧本字段及媒体来源完成独立验收；M2–M9各自接消费者。所有步骤未覆盖前不宣称全平台可配置化；高级缺失治理仍按新清单范围处理，不自动恢复D01。

<a id="056-分模块及组合验收要点"></a>

### 0.5.6 分模块及组合验收要点

- **配置**：至少两套JSON布局、两种语言及一个非剧本字段，纯配置贯通解析/表单/下游；输入/输出同源、基本缺失语义明确、未知字段按策略处理。各消费者在所属模块验证。
- **源头**：剧本生成/结构化保留正文、对白及自定义字段；建立实体/变体/逐镜关系，不按译名猜对象或把发言人全部当可见角色；可用隔离结构化样例独立验设定。
- **自动链**：空素材库中新剧本自动产生素材需求，生成主图后按配置选定，再真实参考主图生成变体，结果自动入库并传给镜头。全自动模式不在每张图/字段等待人审；人工模式保留明确入口。
- **独立素材库**：无剧本/配方时完成主图与变体的上传、选取、模型生成、预览及版本关联；可选绑定Bible，未绑定素材仍可用于参考生视频；与配方结果使用同一份素材。
- **依赖和复用**：未取得主图不能生成变体；上传/选择已有变体无模型调用。显式复用素材可跳过对应生成目标；不能静默丢弃参考图或把上传结果标成生成结果。
- **精确引用**：同人物多服装/多视角、不同媒体用途及输入顺序变化均对应实际素材和槽位；无需每镜重选已有明确结果，歧义与缺文件显式处理。
- **提示词**：在外观锚点/prompt_hint等放测试哨兵，核对视频辅助输入和最终正文无系统重复注入；不靠关键词裁剪人工正文。完整提示词、分项长度和准备记录字节数可核对，接口超限仍展示全文，不恢复D01。
- **恢复与交付**：成功项不重跑，失败项可处理；实际返回存在就可查看，缺失不补造。用已有视频独立验证选片/装配/播放/导出，再用新链产物组合复验。
- **工程与试用**：每模块执行匹配的代码/接口/类型/页面/隔离迁移验证及残留搜索，集中交用户验收。不机械重复全套回归；测试、部署和真实产出分开记录。现用库/服务/真实调用在实际执行阶段按用户指令处理，不由本次文档变更触发。
