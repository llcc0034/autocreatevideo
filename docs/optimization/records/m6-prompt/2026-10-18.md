## 页面配置方式

1. 系统设置 → 提示词策略 → 版本详情 → 业务组合规则 → 添加/编辑字段。字段定义仍只定义身份、类型等公共信息，不为某个模型单独登记接收位置。
2. 在“字段内容如何获得”选择“内容生成方式”；用“主要内容来源”选择本次文本或确切结构路径，在“额外参考信息”单独选择需要的资料。声明式字段可选择自身确定性投影原文，不需要人工再填一份输出。
3. “生成结果如何使用”选择最终字段值（final）：采用后直接作为该条规则的正文，按其标签、顺序、分隔符和通道装配。需要模板插入的逐单元导演等仍选投影贡献（contribution）；这两类用途不互相冒充。
4. 发布策略后，以执行实例新版本明确引用并配置字段生成/翻译辅助实例，再通过原素材、配方或烟测入口提供本次值与采用规则。新版本不会自动替换历史执行/Run。
