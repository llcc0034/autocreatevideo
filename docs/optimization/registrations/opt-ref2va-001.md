## OPT-REF2VA-001 动态参考视频语义标签与逐镜匹配辅助

<a id="已落地基础-1"></a>

### 已落地基础

- Shot 已能保存精确实体与 Asset reference binding；ProductionRun 人工页面可逐镜选择 0..N 条参考视频，并明确用途、配对、音频使用和预处理。
- 审批提交完整 binding，服务端在事务中冻结并在 prompt compile 时复核；逐镜选择不再是本项缺口。

<a id="剩余缺口"></a>

### 剩余缺口

- Asset 仍只有通用 metadata，缺少动作类型、运镜、节奏、主体数量和镜头尺度等受控视频语义。
- 当前筛选主要依据类别、时长、FPS、hash 与 owner，不能按 Shot narrative 提供可解释的匹配候选；unattended 路线也缺少逐镜语义选择策略。
- 系统尚无“无参考/匹配参考/不匹配参考”的正式对照证据，不能把链路 Smoke 素材当作全剧默认。

<a id="历史证据2026-08-26-1"></a>

### 历史证据（2026-08-26）

- 当时实测 Asset `67069cf0-…` 是链路 Smoke 素材，画面与“雨夜车站、发光怀表”剧情无关；没有观察到室内语义泄漏，但无关视频仍可能影响动作和运镜。

<a id="剩余方案与验收"></a>

### 剩余方案与验收

1. 通过服务端受控目录为动态视频补充动作、运镜、节奏、主体数量和镜头尺度标签；标签、来源与审核状态可查询，不靠自由文本猜选。
2. 在 Storyboard/ProductionRun 中按 Shot 显示可解释的筛选结果，由人工或注册策略明确选择；没有匹配项时失败关闭或保持无参考，不静默选择全剧默认视频。
3. 用相同 Shot 和冻结输入比较无参考、匹配参考与不匹配参考的抽帧和运动差异，验证筛选价值后再允许 unattended 策略使用。
