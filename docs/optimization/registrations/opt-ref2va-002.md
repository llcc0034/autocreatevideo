## OPT-REF2VA-002 短镜头动作方向稳定性

<a id="已落地缓解"></a>

### 已落地缓解

- PromptProfile 已提供数据驱动的短镜动作密度 advisory；媒体候选可以同步播放、拖动和并排比较。
- 这些能力帮助人工发现问题，但还没有生成可审计的首/中/尾动作 QA 结论，也没有“拿起/放下”等方向动作 evaluator 或自动选片门禁。

<a id="历史证据2026-08-26-2"></a>

### 历史证据（2026-08-26）

- 当时镜头 1 的提示词明确写“弯腰拾起怀表”，22 帧结果却表现为逐步把怀表放到地面；镜头 2 的“举表、暖光照脸、远处人影”符合叙事。
- 人物、场景和道具一致性通过，因此该案例属于动作时序质量问题，不是实体绑定或媒体探测故障，也不代表当前每次运行都会复现。

<a id="当前操作口径"></a>

### 当前操作口径

对“拿起/放下、进入/离开、打开/关闭”等方向动作必须检查首中尾帧；半自动/人工线不符合时修改 narrative、改用动作匹配参考视频并重新生成。全自动线应在未来接入动作方向评估器后再允许策略自动选片。

<a id="继续投入触发条件"></a>

### 继续投入触发条件

- 当前由人工候选比较承担质量门禁。只有方向错误在更多真实样本中持续出现，或无人值守批量生产需要自动选片时，才进入 evaluator 实施。
- evaluator 必须输出可审计的动作方向证据和置信度；未确认或低置信度继续交给人工，不能把技术成功自动改判为叙事通过。
