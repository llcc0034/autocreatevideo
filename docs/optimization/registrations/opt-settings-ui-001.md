## OPT-SETTINGS-UI-001 系统设置列表搜索、筛选与退役记录默认隐藏

<a id="改造前现状"></a>

### 改造前现状

- 系统设置中的 Provider、模型版本、Deployment、模型文件、工作流版本、PromptProfile、Binding、Recipe、运行主机等列表会持续增长；改造前主要依赖滚动浏览，查找名称、Key、版本或状态效率较低。
- 已退役版本与当前可用配置混排并默认展示，历史记录较多时会遮挡草稿、已发布、启用或需要处理的对象。
- 已退役记录仍是必要的不可变审计事实，只应从默认工作视图隐藏，不能删除或从服务端事实中丢失。

<a id="已落实方案"></a>

### 已落实方案

1. 为系统设置各主要列表提供分区内搜索，至少支持显示名称、稳定 Key、版本号、对象 ID 和能力 operation 等常用字段。
2. 提供明确的状态筛选；默认排除 `retired`，并设置“显示已退役（Include retired）”开关及隐藏数量提示。
3. 草稿、已发布、启用、禁用、失败、待处理等当前工作状态默认正常展示；是否隐藏只由用户可见筛选条件决定，不改写服务端状态。
4. 搜索结果、状态筛选、列表计数和空状态保持一致；无结果时区分“没有记录”和“记录被当前筛选隐藏”。
5. 数据量需要分页时，由服务端提供稳定的搜索、状态过滤、排序与分页口径；前端不通过只过滤当前页制造不完整结果。

<a id="实施状态2026-08-30"></a>

### 实施状态（2026-08-30）

- 已上线统一搜索、状态过滤与“显示已退役/停用记录”开关；退役审计事实默认隐藏但可随时恢复查看。
- 模型页按 `profile_key` 聚合模型卡片；每个能力版本把“能力概览”和“文件与证明”合并为一行紧凑信息摘要，按需展开详情，“运行实例”保留独立折叠区。
- 模型搜索覆盖版本、相对路径、库存选择器、存储 URI 与运行实例；命中内部对象时自动展开所属模型与版本，所属 retired 版本及实例默认一并隐藏。
- 版本、文件与运行实例的操作按对象和生命周期就近展示；实例生命周期与 Smoke 证据分开呈现，停用、重新启用、删除空记录及退役保留历史仍使用原有服务端门禁。

<a id="验收条件-1"></a>

### 验收条件

- 首次进入任一受影响列表时不展示已退役记录，并明确提示隐藏数量及恢复显示入口。
- 开启“显示已退役”后可搜索并查看历史记录，关闭后立即恢复默认工作视图。
- 使用名称、Key、版本、ID 或 operation 搜索时返回完整且准确的结果；分页场景不会漏掉非当前页匹配项。
- 搜索、筛选、重新读取和分区切换不会造成状态误写、选择错位或将退役对象误当成当前对象。
- 相关前端测试与系统设置桌面页面浏览器验收通过，并覆盖空结果、仅退役命中和大量版本记录。
