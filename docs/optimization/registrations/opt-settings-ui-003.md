## OPT-SETTINGS-UI-003 工作流与能力关联验收页面的统一视觉收敛

<a id="当前现状与决定2026-09-05"></a>

### 当前现状与决定（2026-09-05）

- 工作流列表与能力关联总览已经采用统一关联按钮；配置状态与在线校验、真实 Smoke 状态分开展示。
- 本轮截图评估仍发现数量旁空心点近似重复的零、历史记录占据首屏、顶部信息和工作流行高偏大。截图右侧截断是否为实际页面溢出尚未验证。

<a id="后续范围与实施顺序"></a>

### 后续范围与实施顺序

1. 区分数量徽标与状态信号灯，简化按钮文案；保留配置、引用与验收结论的语义边界。
2. 能力总览默认聚焦当前有效对象，历史／停用记录通过显式筛选查看；筛选、分页和数量必须保持同一统计范围，不通过客户端隐藏行伪造总数。
3. 压缩顶部导航、说明和搜索区域；工作流的“更多关联”移至名称或操作区，适度降低行高，保留可点击面积与清晰焦点。
4. 统一长名称的全文查看、关联跳转和不同视口布局，检查截断、溢出及操作可达性。

<a id="启动条件影响与验收"></a>

### 启动条件、影响与验收

- 业务逻辑与关键验收链路基本稳定，并经用户确认进入统一视觉优化阶段后再启动；届时重新核对页面，不直接沿用截图中的旧状态。
- 主要落点为 `frontend/src/components/ConfigurationRelationButton.vue`、`WorkflowConfigurationLinks.vue` 与 `RegistryRelationsPanel.vue` 及相关展示组件；若筛选需 API 配合，再按正式契约同步调整，不新增事实来源。
- 验收覆盖零／多关联、缺配置、失效引用、历史／停用、加载失败、分页筛选、键盘焦点、精确对象跳转及主要桌面／窄屏视口；重要错误不可因折叠而被掩盖。
- 本次仅登记计划，不代表上述调整或浏览器交互验收已完成；本项不改变或删除关联数据，也不放宽发布与执行门禁。
